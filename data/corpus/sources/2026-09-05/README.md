These are source transcriptions, not generated ancient text. Reading extraction
omits editorial headings, footnote links, notes and deleted readings and normalizes
whitespace; the retained files preserve the editorial encoding for inspection.

<https://bkv.unifr.ch/fr/works/cpl-260> and BiblIndex/CNRS (CPL 260).

Source-specific terms apply to these transcriptions and extracted source text;
the repository's general CC BY 4.0 notice does not replace them. No Dihle PDF or
page image is redistributed: its existing quotation was checked against the
user's copy, and only the corrected locator and file digest are recorded.

Conventional ancient loci remain sufficient citation. Source edition metadata
identifies the wording and variants; a missing printed page is not a reason to
call an ancient source inauthentic.
