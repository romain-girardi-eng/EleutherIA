# Domus 2026 Presentation Assets

This folder holds the working media for `docs/presentation-domus-2026.html`.

- `exports/` contains rendered slide snapshots and intermediate variants kept for documentation and review.
- `../karpathy-photo.jpg` and `../karpathy-tweet.webp` are referenced directly by the HTML deck.

Keeping these assets under `docs/assets/` avoids polluting the repository root with presentation exports while preserving the source material used for talks and documentation.
