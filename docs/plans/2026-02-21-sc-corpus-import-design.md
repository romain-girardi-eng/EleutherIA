## 1. Objectives

### Primary Goal
Ingest the 40 source-language files from the *Sources Chrétiennes* corpus into EleutherIA's dual-layer architecture:
- **Textual layer**: `ancient_works` + `passages` tables (readable, searchable)
- **Knowledge graph layer**: `kg_nodes` + `kg_edges` tables (traversable, agentic)

### Core Constraints
- **ZERO hallucination**: All `text_content` in passages and KG nodes is extracted verbatim by script. No LLM touches the original text.
- **Original language only**: Greek or Latin source text exclusively. No translation, no commentary, no paraphrase.
- **No custom referencing**: Use the existing SC reference system (book, chapter, paragraph) as-is.
- **Work descriptions from INDEX.md**: The only prose written for KG Work nodes is derived from the pre-existing `INDEX.md` and `MANIFEST.json`, not generated by LLM.

### Secondary Goals
- Lay the groundwork for Phase 2 (bilingue-only Latin works: Commentaire Romains, Homélies Genèse)
- Define the cleanup protocol for existing Alexander de Fato nodes (Phase 3)

## 3. Architecture Decision

### Option C: Full Dual-Layer Integration

```
SC source file (*.txt)
        │
        ▼ [parser.py — pure regex, no LLM]
  Structured data (SCWork, SCChapter, SCParagraph)
        │
        ├──▶ ancient_works (1 row per work)
        │         │
        │         └──▶ passages (1 row per paragraph block)
        │                    │
        │                    └──▶ passage_citations (links to chapter KG node)
        │
        └──▶ kg_nodes: Work node (1 per work, with page-index tree in metadata)
                  │
                  └──▶ kg_nodes: Chapter nodes (1 per chapter/logical section)
                            │
                            └──▶ kg_edges: Work → has_chapter → Chapter
```

### Granularity Decisions

| Layer | Unit | Rationale |
|-------|------|-----------|
| `passages` table | **Paragraph** (one `=====`-delimited block) | Maximum granularity for RAG retrieval and full-text search |
| `kg_nodes` (chapter) | **Chapter** (group of paragraphs sharing same chapter ref) | Coherent argumentative unit for KG traversal |
| `kg_nodes` (work) | **Work** (or Book for multi-book works) | Top-level navigation node |

**Exception — Contre Celse**: This work has only paragraph numbering (no sub-chapters). KG nodes are at **paragraph level** (each `[par.: N]` = one KG node). This is natural because each Contre Celse paragraph is a self-contained response to Celsus's argument.

## 5. Data Model

### 5.1 `ancient_works` Table

One row per **file** (= one book or logical work unit). For multi-book works (Contre Celse, Ad Autolycum), each book gets its own `ancient_works` row to preserve the book-level identity.

```python
AncientWork(
    canonical_id    = "sc507_iustinus_apologia_i",          # = KG Work node_id
    title           = "Apologie I pour les chrétiens",
    title_original  = "Ἀπολογία ὑπὲρ Χριστιανῶν",         # from file header TITRE ORIGINAL
    author          = "Iustinus Martyr",
    author_original = "Ἰουστῖνος",
    language        = "grc",                                 # or "lat" for SC464, SC79 (if Greek)
    period          = "Imperial",                            # mapped manually per author
    school          = "Christian Apologetics",               # mapped manually
    source          = "sources_chretiennes",
    division_scheme = "chapter",                             # or "chapter.paragraph" or "paragraph"
    citation_levels = ["chapter"],                           # or ["chapter", "paragraph"]
    metadata = {
        "sc_number":    "507",
        "sc_edition":   "Ch. Munier, 2006",
        "sc_volume":    "SC 507",
        "date_composed": "c. 150-155 CE",
        "corpus_file":  "SC507_Iustinus_martyr_Apologie_livre_1_source.txt",
        "kg_work_node": "sc507_iustinus_apologia_i",
        "phase":        1
    }
)
```

**Language codes:**
- `grc` — all Greek texts
- `lat` — SC464 (Pamphile, Latin via Rufin), SC79 Chrysostome check needed

### 5.2 `passages` Table

One row per **paragraph block** (delimited by `==================================================` in source files).

```python
Passage(
    work_id          = <UUID of AncientWork>,
    canonical_ref    = "I.4",             # Formatted from parsed reference
    cts_urn          = "urn:sc:507:1.4",  # Custom SC pseudo-URN (see §6)
    book             = "I",               # or None if single-book work
    chapter          = "4",
    section          = None,              # paragraph within chapter if applicable
    subsection       = None,
    sequence_number  = 4,                 # 0-indexed sequential counter within work
    text_content     = "Ὀνόματος μὲν οὖν...",  # EXACT original text, stripped of page markers
    citation_hierarchy = {
        "book":      "I",
        "chapter":   "4",
        "sc_number": "507"
    }
)
```

**Text cleaning rules (applied by script, not LLM):**
1. Remove page number markers: `--- 126 ---` → remove
2. Remove section headers within text: `### ΤΙΤΛΟΣ ###` → remove (keep as metadata)
3. Strip leading/trailing whitespace per paragraph
4. Preserve all diacritics, polytonic Greek, medieval Latin orthography exactly
5. Normalize internal line breaks (hyphenated words across lines) → rejoin

## 6. ID and Reference System

### 6.1 Pseudo-CTS URN for SC texts

Since SC texts have no official CTS URN (proprietary edition), we create a custom SC URN:

```
urn:sc:{sc_number}:{book}.{chapter}.{paragraph}
```

**Examples:**
| Work | Passage | SC URN |
|------|---------|--------|
| Justin Apology I, ch. 4 | `urn:sc:507:1.4` |
| Justin Apology I, ch. 4, §3 | `urn:sc:507:1.4.3` |
| Origène De Principiis III.1.1 | `urn:sc:268:3.1.1` |
| Origène Contre Celse I, §1 | `urn:sc:132:1.1` |
| Ignace, Éph. I.1 | `urn:sc:10bis:eph.1.1` |
| Clément, 1 Cor. ch. 5 | `urn:sc:167:1.5` |

**Rules:**
- `sc_number` from filename: `SC507` → `507`, `SC10bis` → `10bis`, `SC53bis` → `53bis`
- `book` from file header LIVRE field or filename suffix (livre_1 → 1)
- `chapter` from parsed reference header
- `paragraph` from parsed reference (omitted if single paragraph per chapter)

### 6.2 KG Node_id Convention

```
sc{sc_number}_{author_slug}_{work_slug}[_{book}][_{chapter_ref}]
```

**Slug rules:**
- Lowercase
- Spaces → `_`
- Accents stripped (ASCII-safe)
- Special chars removed
- Max 80 chars

**Examples:**
```
sc507_iustinus_apologia_i                    # Work node
sc507_iustinus_apologia_i_chap4             # Chapter node
sc132_origenes_contra_celsum_i              # Work node (CC Book I)
sc132_contra_celsum_i_par1                  # Paragraph node (CC has no sub-chapters)
sc268_origenes_peri_archon_iii              # Work node (De Principiis III excerpts)
sc268_peri_archon_iii_chap1                 # Chapter node (III.1 De arbitrii libertate)
sc10bis_ignatius_ad_ephesios                # Work node (Ignatius to Ephesians)
sc10bis_ignatius_ad_ephesios_chap1          # Chapter node
sc167_clemens_epistula_ad_corinthios        # Work node (1 Clement)
```

## 7. File Parser Design

### 7.1 File Structure Overview

Every source file has:
1. **Header block** (top of file, before first `====` separator)
2. **Content blocks** (separated by `==================================================`)
3. Each content block has a **reference header** (`[...]`) followed by text

### 7.2 Reference Format Variants

Four distinct formats exist across the corpus, each requiring its own regex:

#### Format A — Contre Celse (no chapter, only paragraph)
```
[par.: N]
```
- Files: SC132 (I, II, Préface), SC136 (III, IV), SC147 (V, VI), SC150 (VII, VIII)
- Chapter concept: none (each paragraph = one KG node)
- Regex: `^\[par\.\: (\d+)\]$`

#### Format B — De Principiis extraits grecs
```
[liv.: 3, chap.: 1, par.: 1]
```
- Files: SC268 (livres 3 et 4)
- Chapter: `chap.` value; paragraph: `par.` value
- Regex: `^\[liv\.\: (\d+), chap\.\: (\d+), par\.\: (\d+)\]$`
- **Extra step**: strip `--- TRADUCTION ---` sections and all text after them within each block

#### Format C — Justin Martyr, Athenagoras, and similar Apologistes
```
[première apologie, chap.: N]
[salutation]
```
- Files: SC507, SC379, SC470, SC528
- Chapter: `chap.` value; no paragraph numbering at header level
- Regex: `^\[.+, chap\.\: (\d+)\]$` or named section `^\[([^\]]+)\]$`

#### Format D — Ignatius, Clement, Barnabas, Hermas, Melito, Martyrium, Pamphile, Chrysostome
```
[chap.: N, par.: N-N]
[chap.: N]
[salutation]
[§ N]
[page: N]
```
- Most patristic source files
- Chapter from `chap.` or `§`; paragraph range optional
- Regex cascade: try most specific first, fall back to named section

### 7.3 Text Cleaning Pipeline

Applied to every extracted text block (ORDER MATTERS):

```python
def clean_text(raw: str) -> str:
    # 1. Remove page number markers: "--- 126 ---"
    text = re.sub(r'---\s*\d+\s*---', '', raw)

    # 2. Remove section title markers: "### TITLE ###"
    text = re.sub(r'###[^#]+###', '', text)

    # 3. Rejoin hyphenated line breaks (word split across lines)
    text = re.sub(r'(\w)-\s*\n\s*(\w)', r'\1\2', text)

    # 4. Normalize whitespace (preserve paragraph structure)
    text = re.sub(r'\n{3,}', '\n\n', text)
    text = text.strip()

    # 5. Strip TRADUCTION sections (SC268 only):
    if '--- TRADUCTION ---' in text:
        text = text.split('--- TRADUCTION ---')[0].strip()

    # 6. Remove SOURCE/LATIN markers themselves
    for marker in ['--- SOURCE ---', '--- LATIN ---']:
        text = text.replace(marker, '').strip()

    return text
```

### 7.4 Special Cases

**SC268 Extraits grecs**: Each block contains both `--- SOURCE ---` (Greek, keep) and `--- TRADUCTION ---` (French, strip). Some blocks have SOURCE appearing twice (manuscript variants). Keep only the first SOURCE section.

**Martyrium Polycarpi Inscription**: Very short text, may be a single block with no chapter reference. Map to `canonical_ref = "inscription"`.

**Hermas, Pasteur**: Uses a complex reference system (Visions, Mandates, Similitudes). Reference headers may read `[vision N, chap.: N]` or `[mandat N]`. Map to Format D with named section fallback.

**SC464 Pamphile** (Latin): Header includes `TRADUCTEUR: Rufinus`. Language = `lat`. The file text is Latin (Rufin's Latin translation/adaptation — this IS the primary surviving text of the work). Process as Latin, language code `lat`.
