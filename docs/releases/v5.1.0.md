# EleutherIA v5.1.0 — Enforced Verification Release (2026-06-10)

Frozen scholarly release under the Zenodo concept DOI `10.5281/zenodo.17379489`.
KG snapshot: **2026-06-05** (`data/kg/nodes.jsonl` / `edges.jsonl`).
All statistics machine-generated by `scripts/gen_stats.py` → `data/stats.json`.

## Headline

Before this release, EleutherIA's zero-fabrication guarantee was enforced by
prompts. v5.1.0 makes it enforced by code, measured in CI, and visible to the
reader on every product surface. The full goal framework is documented in
`docs/plans/sota-roadmap.md` (15 goals, G1–G15, all shipped in this release
except the data-remediation items that are deliberately manual).

## Answer-time verification (new)

- **Quote-fidelity gate** (`ProgrammaticVerify`): every quoted ancient-language
  span — blockquotes, double quotes, guillemets, single curly quotes, German
  quotes — must be contained verbatim (accent-, final-sigma- and
  punctuation-folded, word-boundary-aligned, elision-segment-ordered) in the
  passage it cites, or the line is dropped and recorded in
  `metadata.unsupported_quotes`. Unquoted Greek in prose and unquoted Latin in
  blockquotes are checked too. Unsupported quotes are deleted, never silently
  rewritten as prose.
- **Ancient-text verifier** (`text_verifier`, re-enabled): whitelist-first
  against retrieved evidence (no DB round-trip), then a bounded corpus probe
  for residual Greek runs and quoted Latin spans. Report-only by default
  (`ELEUTHERIA_TEXT_VERIFIER=true`), enforcement gated by
  `ELEUTHERIA_TEXT_VERIFIER_ENFORCE`.
- **Adversarial claim audit** (`CitationVerifierV2`, now wired in production,
  `ELEUTHERIA_VERIFIER_V2=true`): re-fetches cited passages fresh and audits up
  to 8 claims per answer (Greek-quoting and low-confidence claims first);
  verdicts stream to the client as `citation_verified` SSE events; REJECTED and
  MISSING claims are downgraded in the claim ledger.
- **Honest grounding score**: `verified_claims / total_claims` with explicit
  method and coverage labeling (formerly a constant).
- **Integrity flags**: KG nodes carrying `metadata.integrity_status` have their
  descriptions excluded from evidence, context packs, and the verifier
  whitelist on every retrieval path.

## Evaluation harness (new)

- `tests/eval` runs in CI: a fabrication **must-never-appear suite** and
  **citation precision/recall gold**, both derived mechanically from the
  project's manual integrity audits (`scripts/eval/build_gold_from_audit.py`),
  plus an adversarial regression suite for the quote gate.
- Online harness (`tests/eval/run_eval.py`) extended with per-passage citation
  P/R scoring and the offline CitationVerifierV2 as faithfulness judge.

## Retrieval correctness

- Lemma search now resolves to passages (not arbitrary slices of a work);
  passage anchors survive into evidence bundles; full passage text (no 800/1600
  char truncation) feeds synthesis and quote verification.
- `passage_role='original'` filter on primary-text legs (paraphrase stubs can
  never pose as corpus text); retrieval step errors are reported in
  `metadata.retrieval_errors` instead of being swallowed as empty results.
- Deep mode (`mode=deep`) is live end-to-end: counter-evidence hunting,
  evidence-sufficiency continuation (bounded), optional cross-encoder reranker.

## Semantic layer / FAIR

- Removed an inference rule that fabricated `argues_for` edges from every
  `supports` edge; corrected `wrote`/`influences`/`defines`/PROV vocabulary
  mappings; inferred triples are materialized into a named inference graph and
  proof chains carry real premise confidence (no longer hardcoded 1.0).
- RDF export now emits per-edge provenance (auto_generated, wave, confidence,
  source_model), a VoID/DCAT dataset description, CC BY 4.0 licensing, and the
  Zenodo DOI.

## Corpus tamper-evidence

- `passages.text_sha256` + `text_provenance` JSONB (migration
  `20260610_03_text_integrity.sql`); ingestion paths populate checksums;
  `audit_text_drift.py` detects any silent mutation of corpus text against a
  committed baseline. Edition-provenance backfill is generated as reviewable
  SQL — Scaife-ingested works are flagged `NEEDS MANUAL EDITION ATTRIBUTION`,
  never guessed.

## Data governance

- All 2,185 open integrity findings consolidated into
  `data/audit/review_queue.jsonl` with an item-by-item adjudication CLI
  (`eleutheria audit-queue`); no bulk operations by design.
- `kg_work_id` collision gate in CI (11 known groups allowlisted and
  enumerated in `data/audit/kg_work_id_collisions_report.md` for manual
  remediation; any new collision fails CI).
- Security: hardcoded production credentials removed from all tracked files
  (rotation required — see ops runbook), constant-time token comparison, API
  keys moved to headers, rate limiting on LLM endpoints, ownership checks on
  traces and drafts.

## Truthful statistics

Earlier READMEs and metadata overstated the corpus (487 works / 69k passages).
All public numbers are now generated from the dataset snapshots and the
overstated figures are corrected everywhere (README, API reference,
`.zenodo.json`, `CITATION.cff`).
