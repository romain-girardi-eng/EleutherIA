Accessibility Statement

Last updated: November 2025

WCAG 2.1 AA - Partially Conformant

EleutherIA is committed to ensuring digital accessibility for people with disabilities. We are continually improving the user experience for everyone, and applying the relevant accessibility standards.

Conformance Status

The Web Content Accessibility Guidelines (WCAG) defines requirements for designers and developers to improve accessibility for people with disabilities. It defines three levels of conformance: Level A, Level AA, and Level AAA.

EleutherIA is partially conformant with WCAG 2.1 level AA. Partially conformant means that some parts of the content do not fully conform to the accessibility standard.

Accessibility Features

Navigation and Structure

  • Skip navigation links to jump directly to main content
  • Consistent navigation across all pages
  • Proper heading hierarchy (H1-H6)
  • Landmark regions (header, nav, main, footer)
  • Breadcrumb navigation for wayfinding

Visual Design

  • Minimum color contrast ratio of 4.5:1 for normal text
  • Text resizable up to 200% without loss of functionality
  • No content that flashes more than three times per second
  • Respects user preferences for reduced motion
  • Visible focus indicators for keyboard navigation

Interactive Elements

  • All interactive elements are keyboard accessible
  • Clear focus indicators on all focusable elements
  • Form inputs have associated labels
  • Error messages are descriptive and helpful
  • Touch targets are at least 44x44 pixels

Assistive Technology Support

  • Compatible with screen readers (NVDA, JAWS, VoiceOver)
  • ARIA attributes for dynamic content
  • Live regions for status updates
  • Semantic HTML for proper structure

Known Limitations

Despite our efforts, some content may not be fully accessible. The following known issues are being addressed:

Area Issue Conformance Plan
Knowledge Graph Visualization Complex interactive graph may be difficult to navigate with screen readers Partial Providing alternative text-based view
Ancient Greek/Latin Text Some polytonic Greek text may not be announced correctly by all screen readers Partial Adding transliterations where possible
Third-party Content External links (Perseus, TLG) may not meet accessibility standards External Clearly marked as external links
PDF Exports Generated PDFs may lack proper document structure Partial Improving PDF accessibility tags

Testing and Evaluation

We evaluate accessibility using:

  • Automated Testing: axe-core for continuous monitoring
  • Manual Testing: Keyboard-only navigation, screen reader testing
  • User Testing: Feedback from users with disabilities
  • Standards Review: Regular WCAG 2.1 AA compliance audits

Technical Specifications

Accessibility of EleutherIA relies on the following technologies:

  • HTML5
  • WAI-ARIA (Web Accessibility Initiative - Accessible Rich Internet Applications)
  • CSS3
  • JavaScript (ES2020+)

These technologies are relied upon for conformance with WCAG 2.1.
